# MT 레크레이션

백엔드 없이 바로 실행되는 MT용 레크레이션 진행판입니다.

## 포함 게임

- 인물 맞추기
- 몸으로 말해요: 속담
- 4글자 릴레이 말하기
- 초성 릴레이 말하기

## 사용 방법

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.

또는 로컬 서버로 실행할 수 있습니다.

```bash
npm start
```

실행 후 `http://localhost:5173`으로 접속하세요.

주의: `app.js`를 직접 실행하는 파일이 아닙니다. 브라우저에서 `index.html`이 불러오는 화면용 스크립트입니다.

- `랜덤 문제 뽑기`: 현재 게임의 문제를 무작위로 표시합니다.
- `정답 보기`: 힌트 또는 정답을 토글합니다.
- `패스`: 다음 문제로 넘깁니다.
- `현재 게임 다시 섞기`: 해당 게임 문제를 다시 랜덤 순서로 섞습니다.
- 인물 맞추기: 한국인 300명, 외국인 200명 풀에서 `한국인만` 또는 `외국인 포함`, `쉬움/보통/어려움/전체` 난이도, 50/100/150/200명 라운드를 설정할 수 있습니다.
- 인물 사진은 Wikipedia/Wikidata에서 사람으로 확인된 페이지의 이미지만 사용하고, 확인되지 않으면 기본 인물 이미지로 대체합니다.
- 스페이스바: 랜덤 문제 뽑기
- `A` 키: 정답 보기

## 배포

정적 파일만 있으므로 GitHub Pages, Netlify, Vercel에 그대로 배포할 수 있습니다.

GitHub Pages 기준:

1. GitHub에 push합니다.
2. Repository Settings > Pages로 이동합니다.
3. Branch를 `main` 또는 배포할 브랜치로 선택합니다.
4. 폴더는 `/root`로 선택합니다.
